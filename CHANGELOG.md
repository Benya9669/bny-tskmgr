# Changelog

Здесь находятся пользовательские заметки о релизах TaskFlow. Заголовок каждого релиза должен точно совпадать с Git-тегом; CI не опубликует версию без подготовленного раздела.

## Unreleased

## v0.2.0

Релиз mobile-ready API и PWA: TaskFlow можно установить как приложение, использовать задачи без сети и синхронизировать изменения после восстановления подключения.

### Главное

- Устанавливаемое PWA с offline-доступом к оболочке, индикатором сети и безопасным обновлением.
- Локальная очередь изменений задач с идемпотентной отправкой и явным выбором серверной или локальной версии при конфликте.
- Sync API с постраничной выдачей до 500 изменений, фиксированным snapshot cursor и gzip-сжатием крупных ответов.

### Аккаунт и совместимость

- Refresh-токены с ротацией, короткоживущие access token, список активных устройств и отзыв сессий.
- Часовой пояс профиля в формате IANA для согласованной интерпретации сроков web- и мобильными клиентами.
- Контракт `/api/v1` зафиксирован OpenAPI и автоматическими contract tests; SQLite schema автоматически обновляется до `17`.

### Обновление

- Перед обновлением создайте консистентный backup по `docs/operations.md`, затем обновите образ и перезапустите Compose без удаления Docker volume.
- Не меняйте `TASKFLOW_SECRET`: это сохранит действующие сессии. Существующие базы схем `1`-`16` обновляются последовательно без удаления пользовательских данных.

### Известные ограничения

- Offline-first реализован в PWA для задач; нативный Android-клиент остаётся целью `0.3.0`.
- Напоминания, фокус-таймер, дневная ёмкость и сохранённые фильтры остаются browser-local состоянием.

## v0.1.1

Patch-релиз с исправлениями компоновки заметок без изменений API, формата экспорта или схемы данных.

### Исправления

- Карточки списка заметок теперь остаются компактными при любом количестве заметок, а переполнение прокручивается только внутри списка.
- Названия папок заметок выровнены по левому краю.
- Markdown toolbar соединён с полем ввода и больше не отделяется от него пустым пространством редактора.

### Совместимость и обновление

- API `/api/v1`, SQLite schema `14` и форматы пользовательских данных не изменялись.
- Установка `v0.1.0` обновляется обычным перезапуском образа без миграций и без удаления Docker volume.

- Исправлена компоновка заметок: карточки списка сохраняют компактную высоту, названия папок выровнены слева, а Markdown toolbar соединён с полем ввода.

## v0.1.0

Релиз полноценного личного рабочего пространства: TaskFlow объединяет задачи, гибкий канбан, недельное планирование, заметки и связанный контекст, сохраняя данные на вашем сервере.

### Главное

- Пользовательские колонки канбана с цветами, системным смыслом, ручным порядком и безопасным переносом задач при удалении.
- Недельный календарь с drag-and-drop планированием, дневной ёмкостью и индикацией нагрузки.
- Markdown-заметки с папками, избранным, полнотекстовым поиском, внутренними ссылками и связями с задачами и проектами.
- Обсуждения в задачах, повторяющиеся задачи, теги, сохранённые фильтры, browser-local напоминания, режим фокуса и неизменяемая история задач.
- Атомарный импорт YouGile: проекты, доски, колонки, задачи, подзадачи и совместимая история обсуждений.

### Аккаунт и безопасность

- Безопасное восстановление пароля по одноразовой ссылке без раскрытия существования аккаунта.
- Изменение имени и подтверждаемая смена email из настроек аккаунта.
- Одноразовые токены восстановления и смены email хранятся только в виде хешей; ссылки используют fragment, поэтому токен не попадает в начальный HTTP-запрос и access logs.

### Совместимость и обновление

- Обратная совместимость `/api/v1` сохранена; OpenAPI обновлён новыми endpoint-ами аккаунта.
- SQLite автоматически мигрирует существующие установки от `v0.0.1` и `v0.0.2` до схемы `14` без удаления пользователей, проектов, задач или истории.
- Форматы экспорта TaskFlow версий 1-9 остаются импортируемыми; текущий экспорт сохраняет новые сущности рабочего пространства.

### Обновление

Перед обновлением создайте консистентный backup по `docs/operations.md`. Обновите образ и перезапустите Compose без удаления volume. Не меняйте `TASKFLOW_SECRET`, чтобы не отозвать действующие сессии. Для восстановления пароля и смены email должны быть заданы публичный `TASKFLOW_PUBLIC_URL` и рабочие SMTP-параметры.

### Известные ограничения

- Напоминания, фокус-таймер, дневная ёмкость и сохранённые фильтры являются browser-local состоянием.
- Android-клиент и offline-first синхронизация ещё не выпущены.

- Добавлен атомарный импорт проектов, досок, колонок, задач и подзадач из JSON-экспорта YouGile.
- Канбан поддерживает пользовательские колонки: создание, переименование, цвет, системный смысл, порядок и безопасное удаление с переносом задач.
- В задачах появились обсуждения с автором и временем: сообщения можно редактировать и безопасно удалять, а изменения доступны через `/sync`.
- Совместимые комментарии и системная история из YouGile переносятся в обсуждения; события подзадач сохраняют контекст родительской карточки.
- Добавлен адаптивный раздел Markdown-заметок с безопасным предпросмотром, автосохранением, папками и избранным.
- Заметки связываются с задачами и проектами, поддерживают внутренние ссылки `[[Название]]` и полнотекстовый поиск по заголовку и содержимому.
- Карточки канбана поддерживают ручной порядок внутри колонок и атомарное перемещение между ними.
- Добавлен недельный календарь с drag-and-drop планированием по дням и зоной задач без даты.
- Переносимый экспорт TaskFlow версии 6 сохраняет ручной порядок карточек; импорт файлов версий 1–5 остаётся совместимым.
- Повторяющиеся задачи поддерживают ежедневный, еженедельный и ежемесячный цикл; следующий экземпляр создаётся после выполнения.
- Переносимый экспорт TaskFlow версии 7 сохраняет правило повторения; импорт файлов версий 1–6 остаётся совместимым.
- Добавлены браузерные напоминания о сроке: в срок, за 15 минут, час или день.
- Переносимый экспорт TaskFlow версии 8 сохраняет настройки напоминаний; импорт файлов версий 1–7 остаётся совместимым.
- Добавлены теги задач, фильтрация по тегу и сохранение наборов фильтров в браузере.
- Переносимый экспорт TaskFlow версии 9 сохраняет теги; импорт файлов версий 1–8 остаётся совместимым.
- В недельном календаре добавлена оценка дневной нагрузки по незавершённым задачам и настраиваемая дневная ёмкость с индикацией перегрузки.
- Добавлены локальный режим фокуса с таймером и неизменяемая история изменений задач.
- Упрощён интерфейс ежедневной работы: мобильная навигация больше не уходит за экран, дополнительные параметры задачи раскрываются по запросу, а фокус, история и напоминания получили понятные состояния.
- Сохранённые фильтры теперь можно безопасно удалить; повреждённые локальные настройки фильтров больше не блокируют загрузку интерфейса.
- Исправлен запуск браузерных напоминаний после загрузки и изменения задач; напоминания работают, пока TaskFlow открыт в браузере.

## v0.0.2

Релиз удобства ежедневной работы: TaskFlow быстрее управляется с клавиатуры, лучше читается на доске и позволяет безопасно переносить пользовательские данные между установками.

### ✨ Главное

- Быстрое создание задачи клавишей `N` и сохранение через `Ctrl+Enter` или `⌘+Enter`.
- Поиск по названию и описанию с совместимыми фильтрами по проекту, статусу, приоритету и датам.
- Быстрый перенос задач между проектами и днями, включая «Сегодня», «Завтра» и «Без даты».
- Независимый срок выполнения в UTC с локальным отображением и подсветкой просрочки.
- Одноуровневые подзадачи и чек-листы с прогрессом, редактированием и синхронизацией.
- Архив проектов без потери задач и связей.
- Переносимый JSON export/import без аккаунта, пароля и токенов; импорт создаёт копии с новыми UUID и атомарно откатывается при ошибке.

### 🎨 Интерфейс

- Публичный адаптивный лендинг Quiet Sanctuary и фирменная иконка Orbit.
- Более широкие и читаемые канбан-карточки на desktop и mobile.
- Подзадачи раскрываются прямо под задачей в списке и канбане и отмечаются без отдельного окна.
- Действия карточки собраны в компактное меню `⋯`, а постоянный элемент перемещения удалён.
- Системные подтверждения и color picker заменены диалогами и палитрой TaskFlow с ручным HEX.
- Добавлены единые SVG-иконки, собственные scrollbar, видимый фокус, skip-link, ARIA-прогресс и live-объявления.

### 📱 API и совместимость

- Обратная совместимость `/api/v1` сохранена.
- `/sync` теперь передаёт `checklist_items` вместе с задачами и проектами.
- Схема SQLite автоматически обновляется до версии `4`; существующие задачи и проекты сохраняются.
- Архив, сроки и чек-листы доступны будущему Android-клиенту через тот же offline-first контракт.

### 🧪 Качество и исправления

- Добавлены Playwright smoke-тесты ключевых desktop/mobile сценариев; CI сохраняет browser trace при ошибке.
- Исправлен асинхронный экспорт, который мог обращаться к уже недоступной кнопке после завершения запроса.
- Исправлена мобильная кнопка архива, которая могла установить некорректный фильтр проекта.
- Проверяются импорт, архив/восстановление, чек-листы, канбан, клавиатурная навигация и сохранение схемы после перезапуска контейнера.

### ⬆️ Обновление

Перед обновлением создайте консистентный backup по `docs/operations.md`. Затем обновите образ и перезапустите Compose без удаления volume. Миграция схемы выполняется автоматически при первом запуске.

Образ релиза: `ghcr.io/benya9669/bny-tskmgr:0.0.2` или `ghcr.io/benya9669/bny-tskmgr:latest`.

### ⚠️ Известные ограничения

- Канбан пока использует четыре системных статуса; пользовательские колонки и ручной порядок запланированы на `0.1.0`.
- Заметки, недельный календарь, повторяющиеся задачи и совместные пространства ещё не реализованы.
- Android-приложение ещё не выпущено; текущий API остаётся основой для него.
- Безопасный выбор локального JSON-файла использует системный диалог браузера.

## v0.0.1

Первый работоспособный self-hosted релиз TaskFlow: спокойный персональный планер, который хранит данные на вашем сервере и уже содержит основу для будущего Android-клиента.

### ✨ Главное

- Единое пространство для входящих задач, плана на сегодня, активных и выполненных задач.
- Проекты с собственными цветами, редактированием и безопасным удалением без потери задач.
- Статусы, приоритеты, дата планирования, описание и оценка времени.
- Адаптивный Calm Editorial интерфейс со светлой и тёмной темами.
- Канбан-доска в стиле Trello/YouGile с четырьмя статусами, drag-and-drop и фильтрацией по проектам.
- Нижняя навигация и прокручиваемые вкладки проектов для мобильной версии.
- Просроченные задачи автоматически остаются в представлении «Сегодня».
- Новые аккаунты активируются только после перехода по одноразовой ссылке из SMTP-письма.

### 📱 Основа Android-клиента

- Версионированный REST API `/api/v1` и машиночитаемый OpenAPI-контракт.
- Клиентские UUID, optimistic locking и tombstone-записи для offline-first синхронизации.
- Инкрементальный `/sync` с курсором и изоляцией данных по владельцу.

### 🐳 Self-hosting

- Готовые Dockerfile, development Compose и release Compose.
- Multi-arch образы `linux/amd64` и `linux/arm64` в GitHub Container Registry.
- Healthcheck с версиями приложения и схемы базы.
- SQLite в WAL-режиме, версионирование схемы и проверенная команда консистентного backup.

### 🔐 Безопасность

- Проект распространяется под сетевой copyleft-лицензией GNU AGPL v3.0 (`AGPL-3.0-only`).
- Пароли хранятся с PBKDF2-SHA256 и уникальной солью.
- Production Compose не запускается без явно заданного секрета подписи токенов.
- Токены подтверждения email хранятся только в виде SHA-256 хеша, ограничены по времени и используются один раз.
- Все операции с задачами и проектами проверяют владельца.
- Опубликованный образ подписывается через Sigstore с GitHub OIDC и получает provenance attestation.

### ⬆️ Установка и обновление

Для нового развёртывания используйте `compose.release.yaml` и задайте уникальный `TASKFLOW_SECRET`. Перед обновлением создайте backup по инструкции `docs/operations.md`, затем выполните `docker compose pull` и `docker compose up -d`.

SMTP, внешний HTTPS URL и адрес отправителя теперь обязательны для новых регистраций. При обновлении все ранее созданные аккаунты автоматически считаются подтверждёнными; миграция схемы `1 → 2` не блокирует существующих пользователей.

Образ релиза: `ghcr.io/benya9669/bny-tskmgr:0.0.1` или `ghcr.io/benya9669/bny-tskmgr:latest`.

### ⚠️ Ограничения первой версии

- Колонки канбана пока соответствуют четырём системным статусам; пользовательские колонки и ручной порядок карточек запланированы на `0.1.0`.
- Пока нет повторяющихся задач, недельного календаря, вложений и совместных пространств.
- Android-приложение ещё не выпущено; текущий API подготовлен для его разработки.
- Токены сессии пока нельзя отзывать отдельно по устройствам.
